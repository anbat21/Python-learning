# Pandas Lab — House Prices (Fish.csv exercise)

## How to run
1. Put `Fish.csv` into this folder.
2. (Optional) Open `config.py` and change CSV_PATH/OUTPUT_PATH if needed.
3. In Terminal:
   ```bash
   python main.py
   ```
4. Program will:
   - Load & explore the data (rows/cols, dtypes, missing)
   - Compute AvgLength and PctHeightToWeight
   - Save as Fish_with_results.csv
   - Ask you to enter one fish and print its metrics
